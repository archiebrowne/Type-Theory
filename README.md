# Type Theory

Material for the Autumn 26/27 DRP on Type Theory @ Imperial.

Reading Material:

* Natural Number Game (Kevin Buzzard et al.): https://adam.math.hhu.de/#/g/leanprover-community/nng4, build the natural numbers from scratch in Lean, one level at a time. Good place to start.
* Russell's Paradox, Stanford Encyclopedia of Philosophy: https://plato.stanford.edu/entries/russell-paradox/, the paradox that started it all, plus the history of how people tried to fix it.
* Thorsten Altenkirch, Should Type Theory Replace Set Theory as the Foundation of Mathematics?: https://arxiv.org/abs/2111.06368, short and opinionated case for type theory over ZFC.
* Andrej Bauer, Five Stages of Accepting Constructive Mathematics: https://math.andrej.com/2016/10/10/five-stages-of-accepting-constructive-mathematics/, what maths without excluded middle actually feels like. Funny, too.
* Vladimir Voevodsky, The Origins and Motivations of Univalent Foundations: https://www.ias.edu/ideas/2014/voevodsky-origins, a Fields medallist explains why he started worrying about mistakes in his own proofs.
* Philip Wadler, Propositions as Types: https://homepages.inf.ed.ac.uk/wadler/papers/propositions-as-types/propositions-as-types.pdf, readable history of the Curry–Howard correspondence.
* Thorsten Altenkirch, Naive Type Theory: https://nottingham-repository.worktribe.com/output/1990007, informal introduction to type theory in the spirit of Halmos's Naive Set Theory.
* Type Theory, Stanford Encyclopedia of Philosophy: https://plato.stanford.edu/entries/type-theory/, overview from Russell's ramified types up to Martin-Löf.
* Daniel Grayson, An Introduction to Univalent Foundations for Mathematicians: https://arxiv.org/abs/1711.01477, how Voevodsky encoded ordinary maths in type theory. Written for working mathematicians.
* Theorem Proving in Lean 4: https://lean-lang.org/theorem_proving_in_lean4/, dependent type theory explained through Lean, with lots of examples to type in.
* Mathematics in Lean: https://leanprover-community.github.io/mathematics_in_lean/, doing actual undergraduate maths in Lean and mathlib.
* Kevin Buzzard, Formalising Mathematics: https://www.ma.imperial.ac.uk/~buzzard/xena/formalising-mathematics-2024/, notes from the Imperial course. Aimed at final years but worth dipping into.
* Egbert Rijke, Introduction to Homotopy Type Theory: https://arxiv.org/abs/2212.11082, our main text. Part I covers dependent type theory from scratch, one lecture per chapter.
* Simon Thompson, Type Theory and Functional Programming: https://www.cs.kent.ac.uk/people/staff/sjt/TTFP/, older but clear account of Martin-Löf type theory from the programming side.
* Nordström, Petersson & Smith, Programming in Martin-Löf's Type Theory: https://www.cse.chalmers.se/research/group/logic/book/, the classic treatment of Martin-Löf's system. Free online.
* Rob Nederpelt & Herman Geuvers, Type Theory and Formal Proof: https://wsinrpn.win.tue.nl/book_type_theory.htm, slow, careful route from lambda calculus to the Calculus of Constructions.
* Martín Escardó, Introduction to Univalent Foundations of Mathematics with Agda: https://arxiv.org/abs/1911.00580, univalent foundations developed in Agda code, step by step.
* The HoTT Book: https://homotopytypetheory.org/book/, the standard reference from the 2012–13 IAS special year. Chapter 1 is approachable, the rest gets hard quickly.
* Girard, Lafont & Taylor, Proofs and Types: http://www.paultaylor.eu/stable/Proofs+Types.html, proof theory of typed lambda calculi, including System F. Dense.
* Michael Shulman, Homotopy Type Theory: A Synthetic Approach to Higher Equalities: https://arxiv.org/abs/1601.05035, where all this leads. Best read at the end.
